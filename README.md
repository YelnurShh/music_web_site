# «Бабалар үні – цифрлық әлемде»

**Қазақтың ұлттық музыкалық аспаптарының интерактивті онлайн-энциклопедиясы**

1–6 сынып оқушыларына, мұғалімдерге және үлкен кісілерге арналған оқу-білім сайты.
Барлық мәтін қазақ тілінде, қарапайым сөздермен жазылған.

**Стек:** Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Firebase (қосымша, өшіріп қоюға болады)

---

## Авторлар

| Кім | Қызметі |
|---|---|
| **Демеуова Тогжан Абдимуратовна** | Ғылыми жетекші |
| **Дөңесова Асылай Кайсарқызы** | Жоба авторы |

Аты-жөні басты беттегі хиро-секцияның оң жағында, «Жоба туралы» бетінде және футерде
көрсетіледі. Мәтінді өзгерту үшін `src/data/authors.ts` файлын түзетіңіз.

### Фотосуреттерді қою

Аты-жөнінің астында дөңгелек аватар тұр. Әзірге ол аты-жөнінің бас әріптерімен
көрсетіледі. Нақты фотосурет қою үшін мына екі файлды салыңыз (аты дәл осылай болуы керек):

```
public/img/teacher.jpg   ← Демеуова Тогжан Абдимуратовнаның суреті
public/img/student.jpg   ← Дөңесова Асылай Кайсарқызының суреті
```

Файл салынғанша әдемі бас әріпті аватар шығады; файл салынған соң фото автоматты түрде
дөңгелек қалыпта көрінеді (қайта құрастыру керек: `npm run build` немесе әзірлеу режимінде
бетті жаңарту жеткілікті). Фотосуреттің атын өзгертсеңіз, `src/data/authors.ts` ішіндегі
`photo` жолын да өзгертіңіз.

## 1. Жылдам бастау

```bash
npm install
cp .env.example .env.local   # Firebase қолданбасаңыз, бұл қадамды өткізіп кетуге болады
npm run dev                  # http://localhost:3000
```

Өндіріс нұсқасы:

```bash
npm run build
npm run start
```

| Команда | Не істейді |
|---|---|
| `npm run dev` | Әзірлеу сервері (Turbopack, ыстық жаңарту) |
| `npm run build` | Статикалық беттерді құрастырады (SSG) |
| `npm run start` | Құрастырылған сайтты іске қосады |
| `npm run lint` | ESLint тексеруі |

Сайт екі режимде жұмыс істейді:

- **Firebase жоқ** (әдепкі) — таңдаулылар, баптаулар, викторина нәтижесі тек пайдаланушының
  браузерінде (`localStorage`) сақталады. Ешқандай тіркелу сұралмайды.
- **Firebase бар** — анонимді кіру арқылы таңдаулылар мен нәтижелер бұлтта сақталып,
  құрылғылар арасында сақталады, «Үздік оқушылар» кестесі жұмыс істейді.

## 2. Firebase қосу (міндетті емес)

1. [Firebase консолінде](https://console.firebase.google.com/) жоба жасап, **Web қолданбасын** қосыңыз.
2. **Authentication → Sign-in method** ішінде **Anonymous** кіруді қосыңыз.
3. **Firestore Database** жасаңыз (production режимінде).
4. `.env.example` файлын `.env.local` деп көшіріп, өз мәндеріңізді жазыңыз:

| Айнымалы | Қайдан алынады | Міндетті ме? |
|---|---|---|
| `NEXT_PUBLIC_FIREBASE_API_KEY` | Жоба параметрлері → Web қолданбасы | Иә |
| `NEXT_PUBLIC_FIREBASE_PROJECT_ID` | Жоба параметрлері | Иә |
| `NEXT_PUBLIC_FIREBASE_APP_ID` | Жоба параметрлері | Иә |
| `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN` | Жоба параметрлері | Жоқ |
| `NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET` | Жоба параметрлері | Жоқ |
| `NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID` | Жоба параметрлері | Жоқ |
| `NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID` | Жоба параметрлері | Жоқ |

`API_KEY`, `PROJECT_ID`, `APP_ID` үшеуі болмаса, сайт автоматты түрде «тек браузерде сақтау»
режиміне ауысады — қате шықпайды, «Жоба туралы» бетінде жағдайы көрсетіледі.

5. Қауіпсіздік ережелерін жүктеңіз (файл: `firestore.rules`):

```bash
npm install -g firebase-tools   # бір рет
firebase login
firebase use <жоба-id>
firebase deploy --only firestore:rules
```

Ережелер қысқаша: әр пайдаланушы тек өз құжатын оқиды/жазады (таңдаулылар ≤ 50, нәтиже 0–16),
ал «Үздік оқушылар» кестесін барлығы оқи алады, тек кірген қолданушы жаза алады (жазған соң
өзгертуге/өшіруге болмайды).

## 4. Функционалдар

**Оқу және іздеу**
- Хидердегі іздеу жолағы барлық аспап, аңыз, тарихи кезең мен сөздіктен табады.
- `Esc` — іздеуді жабады, `↑`/`↓` — нәтижелер арасында жүру, `Enter` — ашу.

**Дыбыс (компьютерде жасалған жуық үн)**
- Әр аспап бетінде «Әуенін тыңдау» батырмасы және 6 нота пернесі.
- Пернелер: `1`–`6` (мәтін жазып отырғанда іске қосылмайды).
- Дыбысты толық өшіру батырмасы бар (`kz_muted`).

**Таңдаулылар мен нәтиже**
- Кез келген аспапты ⭐ арқылы таңдаулыға қосу; басты бетте жеке бөлім шығады.
- Викторинаның ең жақсы нәтижесі сақталады; Firebase қосулы болса, бұлтқа жіберіледі.

**Қолжетімділік (үлкен кісілер мен оқушылар үшін)**
- 🔍 Қаріп өлшемін үш деңгейде үлкейту (`--ui-scale`), баптау сақталады.
- 🌙 Ашық/қараңғы түс режимі — бет жүктелмей тұрып қолданылады (жарық қылып жыпылықтамайды).
- 🔊 Дауыстап оқу (браузердің сөйлеу синтезі, қазақ тілін қолдамаса — орыс тіліне ауысады).
- Теру пернелері: `/` — іздеу, `T` немесе `е` — түс режимі, `+`/`-` — қаріп өлшемі.
- Скринридер үшін skip-link, `aria-*` белгілері, фокус шеңберлері, «қозғалысты азайту» режимі.
- Басып шығаруға арналған стиль (тарих және сөздік беттерінде 🖨️ батырмасы).

## 5. Жоба құрылымы

```
src/
├ app/                      # Next.js App Router беттері
│ ├ layout.tsx              # <html lang="kk">, метадеректер, хидер/футер, түс скрипті
│ ├ page.tsx                # басты бет
│ ├ aspaptar/ aspap/[id]/   # каталог және аспап беттері (generateStaticParams)
│ ├ anyzdar/ tarih/ oiyn/ sozdik/ about/  not-found.tsx
│ └ globals.css             # Tailwind 4 дизайн жүйесі (түстер, .btn, .card, .chip…)
├ components/               # 26 компонент (Header, Footer, ProjectAuthors, Catalog, Quiz, MemoryGame…)
├ data/                     # мазмұн: 5 топ, 14 аспап, 6 аңыз, 8 кезең, 32 сөз, 16 сұрақ, авторлар
├ lib/                      # synth (Web Audio), prefs, firebase, cloud, search, utils, nav
└ providers/AppProvider.tsx # useApp(): баптаулар, таңдаулылар, бұлт жағдайы, хабарламалар
public/
├ img/                      # 15 сурет (10 jpg + 5 png)
└ fonts/                    # 6 woff2 (Manrope, Rubik — кирилл жазуы)
firestore.rules             # Firestore қауіпсіздік ережелері
```

Мазмұнды өзгерту үшін тек `src/data/*.ts` файлдарын түзету жеткілікті — каталог, іздеу,
сүзгі, статистика және жаңа аспап беті автоматты түрде пайда болады.

## 6. Ескертулер (маңызды)

- **Аспап үндері** — компьютерде жасалған жуық үлгі (модель), нақты музыкалық жазба емес.
  Мақсаты — аспап дыбысының реңін (шертпелі, ыспалы, үрмелі, ұрмалы) сезінуге көмектесу.
  Нақты жазба қосу үшін `src/data/instruments.ts` ішіндегі аспапқа `audio` өрісін қосып,
  `SoundButton` компонентінде плеер шақыру керек.
- **Жоба авторлары** — жетекші мен оқушының аты-жөні `src/data/authors.ts` ішінде сақталады;
  фотосуреттер қойылмаса, бас әріпті дөңгелек аватар көрсетіледі (жоғарыдағы «Авторлар» бөлімін қараңыз).
- **Суреттер** — 10 аспап пен хиро-сурет бір стильде жасалған минималистік иллюстрация, ал
  5 аспап (дауылпаз, даңғыра, шыңдауыл, керней, асатаяқ) векторлық суреттен растрланған PNG.
  Музей фотосуреттерімен ауыстыру үшін суретті `public/img/` қалтасына салып,
  `src/data/instruments.ts` ішіндегі сол аспаптың `img` жолын өзгерту жеткілікті.
- **Аңыздар** — халық ауыз әдебиетінің үлгісі. Ғылыми дерек ретінде емес, мәдени мұра ретінде берілген.
- **Жеке деректер** — сайт аты-жөнін, телефонды, email сұрамайды. Firebase қосулы болса да
  тек анонимді кіру пайдаланылады. Жарнама жоқ.
- Қаріптер жергілікті (`public/fonts`) — интернетсіз де ашылады.
