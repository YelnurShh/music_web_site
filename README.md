# «Бабалар үні – цифрлық әлемде»

**Қазақтың ұлттық музыкалық аспаптарының интерактивті онлайн-энциклопедиясы**

1–6 сынып оқушыларына, мұғалімдерге және үлкен кісілерге арналған оқу-білім сайты.
Барлық мәтін қазақ тілінде, қарапайым сөздермен жазылған. Сайт ешқандай серверсіз,
қарапайым HTML/CSS/JavaScript арқылы жұмыс істейді.

---

## 1. Сайтты ашу

Ең оңай жолы — `index.html` файлын браузерде ашу (қосар алдында екі рет басу).

Немесе жоба қалтасында қарапайым сервер іске қосу:

```bash
python3 -m http.server 8000
# содан кейін браузерде: http://localhost:8000
```

Сайт телефонда, планшетте және компьютерде бірдей жұмыс істейді.

## 3. Функционалдар (не істей алады?)

**Оқу және іздеу**
- Бүкіл сайттан іздеу: аспап аты, аңыз, сөздік сөзі, бет атауы (хидердегі 🔍 терезе).
- Пернетақтадағы `/` пернесі — іздеуді бірден ашады.
- Аспаптар бетінде топ бойынша сүзгі, аты бойынша іздеу және реттеу.

**Тыңдау және сезіну**
- Әр аспаптың үнін компьютерлік үлгімен тыңдау (Web Audio API).
- Аспап бетінде «дыбыс пернелері» — өз қолыңызбен дыбыс шығарып көру.
- Ұрмалы аспаптардың ырығын салыстыратын «Ырғақ» жаттығуы.
- Аңыздарды **дауыстап оқу** (браузердің сөйлеу синтезі) — оқуға қиналатын оқушы мен
  үлкен кісіге көмектеседі.

**Ойнау және тексеру**
- Викторина: әр жауаптан кейін түсіндірме шығады, соңында медаль мен қайталау тізімі.
- «Жұп тап» ойыны: аспап суреті мен атауын сәйкестендіру (уақыт пен жүріс саны есептеледі).
- Флеш-карталар: карточканы аударып, аспап туралы қысқаша мәліметті жаттау.

**Қолайлылық**
- 🔍 сайт бойынша іздеу, **A− / A / A+** қаріп өлшемі (үлкен кісілерге өте қолайлы).
- 🌙 ашық/қараңғы түс режимі (баптау браузерде сақталады).
- 🔊 дыбысты толық өшіру.
- ⭐ таңдаулылар тізімі, ⚖️ аспаптарды салыстыру кестесі.
- 🖨️ басып шығару режимі (мәзір мен батырмалар шықпайды).
- Экраннан оқу құралдарына арналған таңбалар (ARIA), пернетақтамен жүру, «негізгі мазмұнға өту» сілтемесі.

**Пернетақта тіркестері:** `/` — іздеу, `T` — түс режимі, `+` / `−` — қаріп өлшемі, `Esc` — терезені жабу.

## 4. Жобаның құрылымы

```
├── index.html            Басты бет
├── aspaptar.html         Аспаптар каталогы
├── aspap.html            Аспап туралы бет (id бойынша)
├── anyzdar.html          Аңыздар
├── tarih.html            Тарих
├── oiyn.html             Ойындар мен викторина
├── sozdik.html           Сөздік
├── about.html            Жоба туралы
├── styles/main.css       Барлық дизайн (минимализм, ашық/қараңғы түс)
├── scripts/data.js       Барлық мазмұн: аспаптар, аңыздар, тарих, сөздік, сұрақтар
├── scripts/synth.js      Дыбыс қозғалтқышы (аспап үндерінің үлгісі)
├── scripts/app.js        Хидер, футер, іздеу, сүзгі, аспап беті, сөздік
├── scripts/games.js      Викторина, «Жұп тап», флеш-карталар, ырғақ
├── assets/img/*.jpg      Аспап суреттері
└── tools/build_pages.py  Беттерді бірдей қалыппен қайта жасайтын көмекші құрал
```

### Мазмұнды өзгерту
Барлық мәтін `scripts/data.js` файлында жинақталған:

- `KZ.instruments` — 14 аспап (аты, сипаты, бөлшектері, үні, тарихы, аңызы, қызықты дерегі).
- `KZ.groups` — 5 аспап тобы.
- `KZ.legends` — 6 халық аңызы.
- `KZ.timeline` — 8 тарихи кезең.
- `KZ.glossary` — 32 сөздік түсінігі.
- `KZ.quiz` — 16 викторина сұрағы.

Бір аспапты қоссаңыз, ол каталогта, іздеуде, топ сүзгісінде және статистикада
автоматты түрде пайда болады.

## 5. Ескертулер (маңызды)

- **Аспап үндері** — компьютерде жасалған жуық үлгі (модель), нақты музыкалық жазба емес.
  Мақсаты — аспап дыбысының реңін (шертпелі, ыспалы, үрмелі, ұрмалы) сезінуге көмектесу.
  Нақты жазбаларды музыка мұғалімінің таспаларынан қосуға болады: `scripts/data.js`
  ішіндегі әр аспапқа `audio` өрісін қосып, плеерді қосу жеткілікті.
- **Аңыздар** — халық ауыз әдебиетінің үлгісі. Олар ғылыми дерек ретінде емес, мәдени мұра
  ретінде берілген.
- Сайтта жарнама жоқ, тіркелу жоқ, жеке деректер сұралмайды. Таңдаулылар мен баптаулар
  тек пайдаланушының браузерінде (`localStorage`) сақталады.
- Интернет қажет тек қаріптер үшін; қалған бәрі жергілікті файлдардан жүктеледі.
